# Compact historical experiments

Previous experiments retain compact numerical summaries, aggregate diagnostics, calibration coefficients, protocol/provenance and audit records, scientific reports, and reproduction scripts. Bulk frame arrays, plots, duplicated source/plot snapshots, logs and Python caches have been removed under the user's cleanup request.

See [CLEANUP_MANIFEST.json](CLEANUP_MANIFEST.json) for removed paths, sizes, hashes, recovery commit and compacted summaries. Raw source detections and fixation definitions remain under `data/`; shared estimator code remains under `distortion_model/`. Non-snapshot experiment scripts are retained, including the raw chain's shared run/audit/plot/helpers scripts. The [raw empirical reference](reverse_transform/raw_keystone/REFERENCE.json) is retained as a small standalone calibration record. The raw shared runner explicitly records skipped historical comparisons when their archived arrays are absent; core fitting still requires its declared parent stages.

Historical audit PASS records describe the original completed runs. This compact archive cannot replay their framewise audits or plots directly because the required arrays/snapshots are omitted. Restore tracked artifacts from the recorded recovery commit or rerun parents in order before invoking consumers. For an exact historical audit replay, restore the original code together with its artifacts, preferably in a separate worktree at the manifest's recovery commit; current retained summaries are historical records, not a fresh post-cleanup numerical audit. Full-state historical comparisons need those restored artifacts. Source-only reproduction reconstructs new arrays and snapshots; it does not turn retained summaries into framewise data.

The next estimator is specified by [NEW_PROTOCOL_PLAN.md](../docs/NEW_PROTOCOL_PLAN.md). Preserve these compact controls and create new stage folders for new work. Cleanup changes artifact retention, not the reported numerical conclusions. No estimator fit or commit was performed during cleanup.
