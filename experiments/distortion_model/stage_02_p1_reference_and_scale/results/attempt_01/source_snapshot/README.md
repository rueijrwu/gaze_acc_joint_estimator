# Source snapshot context

This directory preserves the source files used for this attempt in their original repository-relative layout. Files are copied byte-for-byte; their recorded hashes are in the attempt's `provenance.json`.

Raw fixation data remain at the repository root in `data/fixations/fixation_intervals.json`; raw data are not copied into this snapshot. Consequently, links from these archived source documents to repository data resolve from their original repository context, not from this nested snapshot directory.
