# Current status

Stage 00 P1 scale analyses are complete: the [positive-only P1 joint fit](experiments/archive/reverse_transform/superseded_baseline/p1_joint_keystone_magnification/results/RESULTS.md), [bounded P1 scale sensitivity](experiments/archive/reverse_transform/superseded_baseline/p1_joint_bounded_magnification/results/RESULTS.md), and [fixed-`θ01=0°` sensitivity](experiments/archive/reverse_transform/superseded_baseline/p1_zero_origin_comparison/results/RESULTS.md) remain conditional. The active P1 protocol freely fits one nuisance offset `θ01` shared across its frames; the P4 model has a separate freely fitted `θ04`, with no equality constraint. Neither offset has absolute physical-angle meaning. The fixed-zero result is sensitivity only. In the bounded fit, learned C1 equal-fixation RMS is 0.8328 px, fitted `θ01=42.40°`, and `m` spans 0.9800–0.99495. Constraining `θ01=0°` raises learned RMS to 0.9446 px (+13.43%) and fixed-template RMS to 1.0233 px (+5.63%). Learned `m`/gaze correlation changes from +0.519 to −0.587; fixed-template scales stay nearly unchanged (`r=0.999987`).

The completed [Stage 00 matched P4 scale-effect refit](experiments/reverse_transform/p4_gaze_accommodation_decoupling/stage_00_baseline_sensitivity/p4_p1_scale_effect/results/RESULTS.md) compared `g=1` with the frozen bounded learned-P1 `m` after fully refitting P4. The equal-capture/equal-fixation objective rises from 1.20434 to 1.71720 px² (+42.58%); C1–C3 RMS worsens, while C4 is nearly unchanged. Both selected fits are stationary and all 88,978 rows pass domain checks. The in-sample inverse diagnostic has zero invalid frames and pooled RMS 1.2112 px (`g=1`), 3.0124 px when only P1 `m` is substituted into the fixed `g=1` inverse, and 1.4859 px after full P4 refit under P1 `m`. The fixed-geometry substitution is distinct from the full-refit comparison; see the report for details. This candidate P1 scale does not improve P4 geometry under this model, so keep `g=1` primary and P1 `m` sensitivity-only. The broader P1-to-P4 transfer gate remains unmet: `m` is model-relative, gaze-associated, and not a physical magnification measurement. Next fit `k(A)` and `A` under the `g=1` working primary; do not infer accommodation from this scale comparison.
