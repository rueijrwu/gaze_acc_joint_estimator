# New protocol implementation audit

**As of 2026-10-10.** This document records execution of the Revision 2 shared-keystone S0 protocol through Stage 05. The specification was frozen before implementation at SHA256 `a833ded4b067b95cf028bde3a21f73ca13538aa26b351341640770fe3a44a96d`; the existing [plan audit](../NEW_PROTOCOL_PLAN_AUDIT.md) remains the historical specification audit. The implementation is an empirical, centered-shape estimator conditional on same-recording anchors.

## Numerical audit repairs

1. **Block-merit roundoff (before Stage 03).** The optimizer's projected-gradient merit for a block update was corrected to use only optimized coordinates; the full objective and domains were unchanged. CPU and CuPy regression passed. Evidence: [roundoff regression](../../experiments/archive/reverse_transform/shared_keystone/stage_03_joint_refinement/audits/block_roundoff_merit.json). Stage 01 and Stage 02 remain valid provenance-backed warm checkpoints; Stage 03 used the corrected frozen core.
2. **Saved optical-width-2 curvature audit.** An adaptive feasible finite-difference check recertified the saved Stage 03 control on CPU. The original control certificate remains `UNCERTIFIED`; the supplemental certificate passes and the before/after control hashes match, showing no refit or parameter change. Evidence: [supplemental audit](../../experiments/archive/reverse_transform/shared_keystone/stage_03_joint_refinement/audits/results/optical_20_clean/audit.json).
3. **Stage 05 derivative and GPU roundoff gates.** The audit uses normalized derivative criteria and declares repeatability tolerances for float64 GPU reductions. The first Phase V attempt remains marked uncertified in [attempt_01](../../experiments/archive/reverse_transform/shared_keystone/stage_05_validation/results/attempt_01/RESULTS.md). The repaired canonical run passes training, held-state, and noninterference checks; regression source hashes are in [repair provenance](../../experiments/archive/reverse_transform/shared_keystone/stage_05_validation/audits/regression_provenance.json). The fit objective and shared fit core were not changed for this audit-only repair.

## Remaining decision gate

The optional S1 accommodation-dependent P4-keystone model has **not** been run. Review S0's fixation-dependent accommodation means, active `q[7]` bound, gaze/accommodation box contacts, 13 measured-pattern inverse failures, and held-out residual tail before deciding whether S1 is scientifically justified. A flat fitted A trend by itself does not authorize model promotion. No claim that the anchors recover physiological states is supported by these runs.
